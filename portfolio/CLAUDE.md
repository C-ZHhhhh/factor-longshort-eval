# portfolio/

> L2 文档 | 父级: [../CLAUDE.md](../CLAUDE.md) | 分形协议: 三层结构

## 地位

组合层,负责根据因子值构建多空组合,分配权重,实现market-neutral中性化。

## 边界

**输入**: 标准化后的因子值
**输出**: 中性化后的组合权重序列、换手率

## 约束

1. **分位数选股**: 进入阈值entry_quantile(默认25%) + 退出阈值exit_quantile(默认30%) + 最小持有期;要求 entry_quantile ≤ 0.5 且 exit_quantile ≥ entry_quantile,否则初始化报错
2. **权重归一化**: 多头权重和=+1,空头权重和=-1
3. **中性化验证**: 必须满足 Σw ≈ 0
4. **多空互斥**: 同一只股票同一期不能既在多头又在空头;一侧仍在持有(含被最小持有期锁住)时,另一侧不允许新开仓

## 成员清单

**__init__.py**: 包初始化文件

**portfolio_builder.py**: 排序选股模块(有状态)。根据因子值排序,按进入/退出阈值和最小持有期决定多空持仓,多空两侧一起决策保证不重叠。

**weighting.py**: 权重分配模块。支持等权、市值加权、风险平价等方法。

**neutralization.py**: 中性化模块(⭐ CRITICAL)。实现market_neutral()和beta_neutral()。

**rebalancer.py**: 换手率计算模块。计算TO = 0.5 × Σ|Δw|。
