# tests/

> L2 文档 | 父级: [../CLAUDE.md](../CLAUDE.md) | 分形协议: 三层结构

1. **地位**: 自动化回归测试。锁定影响回测结果正确性的关键约定,任何一条被破坏都应该在这里先红。
2. **边界**: 只依赖项目代码和测试内构造的小数据,不联网、不读data/cache。运行: `python -m pytest`
3. **约束**: 每个曾经出过错的约定必须有对应用例;新增因子/指标时同步补方向与时间对齐的用例。

## 成员清单

**conftest.py**: 公共配置。把项目根目录加入sys.path,降低日志级别,提供daily_prices价格夹具。

**test_factors.py**: 因子方向与时间约定。动量=P(t-1)/P(t-12)-1且赢家因子值高;反转=-R_t,经时间对齐后只滞后一期。

**test_portfolio_builder.py**: 组合构建。多空名单逐期不相交、被最小持有期锁住的多头不会被同时做空、权重资金中性。

**test_backtest.py**: 绩效指标与回测引擎。总收益/年化收益包含第一期;回撤把初始净值算作高点;t期权重对应t+1期收益。

**test_data_cleaner.py**: 月份完整性。不完整的最后一个月不进入月收益率。
